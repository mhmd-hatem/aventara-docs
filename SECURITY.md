# Security policy

## Scope

This policy covers:

- the Aventara Framework packages (`@aventara/*`)
- Aventara Access (`@aventara/access`)
- this documentation site

## Reporting a vulnerability

Report vulnerabilities privately through GitHub's "Report a vulnerability" form:

https://github.com/mhmd-hatem/aventara-docs/security/advisories/new

Please don't open public issues, pull requests or discussions for vulnerabilities.

Include:

- a description of the issue
- steps to reproduce, with the package versions and configuration you used
- the impact you see
- ideas for a mitigation, if you have any

## What happens next

The maintainer aims to patch confirmed issues within 3 to 7 days, then publishes a GitHub security advisory that lists the affected versions and how to upgrade.

## Supported versions

Only the latest release of each package is supported. These are currently pre-1.0 release candidates.
